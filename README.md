# Dipesh Dhakal — Portfolio

Personal portfolio website built with React, TypeScript, Vite, and Tailwind CSS.

## Features

- Hero with rotating roles, stats, and availability status
- About, Skills, Projects (with detail modal), Experience timeline
- Education and Certifications sections
- GitHub repositories section (live GitHub API data with static fallback)
- Contact form (frontend preview) with social links
- Interactive CLI terminal modal and printable resume modal
- Dark cybersecurity-themed UI with particle background

## Commands

```bash
npm run dev      # start dev server
npm run build    # typecheck + production build
npm run lint     # oxlint
npm run preview  # preview production build
```

## Project Structure

```
src/
  components/    # UI components
  data/          # portfolio content (portfolioData.ts)
  assets/        # static images
public/          # images served at root
```
